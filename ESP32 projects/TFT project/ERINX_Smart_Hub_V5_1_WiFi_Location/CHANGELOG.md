# Changelog

## V5.1 (Weather location + Wi-Fi touch setup)
- 4 saved location presets: Malvar, Tanauan, Lipa, Sto. Tomas.
- Location dropdown and on-selection Open-Meteo refresh, with stale weather state cleared.
- Wi-Fi scanning of nearby 2.4 GHz SSIDs, network list pagination and signal strengths.
- Masked on-screen password keyboard with case, symbols, backspace, space, join.
- Connection-status messages, successful-connection persistence using Preferences, auto-reconnect, and manual forget action.
- Preserved V5.0 photo gallery/video decoder, DHT11, NTP, icons and animations.
- Does not attempt to improve TFT transfer performance/FPS; previous SPI benchmark remains applicable.
